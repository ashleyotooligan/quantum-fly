# Accessibility and interaction

The browser toolbar uses native controls with explicit labels and focus outlines. The view selector can reach all fourteen views without clicking Canvas. Status changes have a live region; errors have an alert role. Keyboard shortcuts are disabled while typing in form controls.

The main figures are Canvas, so their values are not yet exposed as equivalent live DOM tables. The README, method documents, raw JSON, and results table provide text alternatives for the static experiment. This is a known accessibility limit of the local viewer, not a claim of complete screen-reader support.

Color accompanies labels for actions, neural groups, policies, and trails. The world and charts use high-contrast text on navy backgrounds. There is no audio. The animation begins paused. On phones, the scene scrolls horizontally rather than squeezing all numerical labels into unreadable text.

Future accessibility work should add DOM tables, visible numeric values for slider positions, and screen-reader testing of checkpoint import/export. Existing scene captures are annotated in the gallery.
