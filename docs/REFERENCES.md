# Primary references

1. Dorkenwald et al. (2024), [Neuronal wiring diagram of an adult brain](https://www.nature.com/articles/s41586-024-07558-y), Nature. DOI: 10.1038/s41586-024-07558-y. A real adult female fruit-fly connectome; it is context, not this model's dataset.
2. [FlyWire](https://flywire.ai/), the project's primary data portal. Consult its original resources for biological wiring and usage terms. None is redistributed here.
3. IBM Quantum Learning, [Quantum information](https://quantum.cloud.ibm.com/learning/courses/basics-of-quantum-information/single-systems/quantum-information). Context for complex states, unitaries, and standard-basis measurement.
4. IBM Quantum Learning, [Bits, gates, and circuits](https://quantum.cloud.ibm.com/learning/courses/utility-scale-quantum-computing/bits-gates-and-circuits). Context for qubits and gates.
5. GitHub Docs, [Adding a file to a repository](https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository). Browser folder upload instructions.
