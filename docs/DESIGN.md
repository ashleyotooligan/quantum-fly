# Visual identity

The specimen is luminous cyan anatomy against deep navy, with violet compound eyes and sparse neural-like lights. The pixel fly provides a compact signature. It is an original generated sprite, not a reused game character.

The UI uses cyan for sensory data and the advance action, violet for recurrence and left, amber for motor data and right, and muted blue-gray for pause. A color identifies an action or group consistently across bars, plots, rasters, and trails. Text labels accompany color.

Panels contain calculated values or original illustrations. Art panels explicitly say illustration. Network position is schematic. The same seed and frame make captures comparable. The sidebar presents observation views rather than invented hardware consoles.

Screens are 1600 × 1000. The viewer uses a fixed Canvas with responsive scaling; on narrow phones it scrolls horizontally to preserve detail. It is optimized for desktop inspection. Image provenance is recorded in [assets/PROVENANCE.md](../assets/PROVENANCE.md).
