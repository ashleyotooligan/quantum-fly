# Scope and public claims

Quantum Fly is an original working local simulation laboratory. It combines a toy spiking controller, a mathematical two-qubit circuit, a procedural world, and observation tools.

Supported statements: the controller generates actual synthetic spike events; the circuit implements explicit gates; changing phase changes readout probabilities; complete dephasing removes that phase dependence for frozen inputs; changing readout odds can change the body's path; checkpoints resume the same model.

It is not a uploaded living brain, a whole-brain emulator, a consciousness experiment, a quantum processor, a trained intelligence model, a biological quantum theory, or evidence of a performance advantage. There are no measured fly neurons or imported connectome weights. The glow in the artwork is illustration.

The project takes inspiration from public interest in fly-brain visualization. It does not verify or repeat specific viral-video claims about real neural activity, trading profits, or brain uploads. Scientific references document the source topic and formalism, not an affiliation.

No accounts, wallets, token contract, exchange integration, or real-money trading system are present. The repo is independently named and authored; all project visuals are new.
