# Visual provenance

The fly silhouette, pixel logo, and macro portrait are original generated illustrations created for Quantum Fly. They are not biological scans, reconstructed neural cells, or imported figures from a research paper. The built-in image-generation tool was used on 2026-10-09. Original PNG outputs were copied into this repository without cropping or recoloring.

The fourteen files in `screenshots/` are generated by `scripts/capture.mjs`, using the same Canvas drawing functions as the browser. They depict the actual default synthetic model and fixed-input experiments. They are native-rendered software figures rather than browser-engine screenshots. Charts, rasters, values, and paths are calculated; art panels identify their illustrative content.

A single tiny fruit-fly-inspired insect, anatomically recognizable with precisely six delicate legs, one pair of translucent wings, a segmented abdomen, round compound eyes, small antennae, and subtle halteres. Three-quarter dorsal-side view, head pointing toward lower right, wings extending toward upper left. The animal is a luminous cyan and ice-blue holographic wireframe sculpture, with fine polygon mesh following the anatomy and sparse violet neural-like points visible inside its head. Beautiful clear readable silhouette, delicate dark-blue transparent surfaces, brilliant cyan edges, violet compound eyes, restrained glow, advanced microscope visualization aesthetic. Isolated on a fully transparent background, no ground plane, no shadow plate, no square background. Entire fly including all wings and legs fits comfortably with generous margin. No captions, no text, no symbols, no logos, no computers, no stock trading scene. This is original stylized artwork, not a scientific scan. Landscape composition suitable for an application specimen panel; high detail with clean negative space.

Fully transparent background, square centered icon with generous empty padding, no photographic rendering, no gradients or anti-aliased curves. Original design, not any existing game character. Polished pixel sprite to sit at the top of a GitHub README and serve as a square repository icon.
